# Simple ATM Simulator — Python Week 1 Project

## 📌 Project Overview
This repository contains a console-based **Simple ATM Simulator** built as part of the **Week 1 Python Programming** curriculum[cite: 33]. It demonstrates modular programming, PIN authentication, exception handling, and user interaction[cite: 33].

---

## 🛠️ Features & Functions
* **User Authentication**: Secure 4-digit PIN verification (`1234`) with a 3-attempt limit[cite: 33].
* **`check_balance()`**: Displays current account balance formatted in currency[cite: 33].
* **`deposit()`**: Handles cash deposits with positive value validation[cite: 33].
* **`withdraw()`**: Validates available funds before dispensing cash[cite: 33].
* **Interactive Menu Loop**: Continuous session handling until the user explicitly selects **Exit**[cite: 33].
